## Unified Schema Explained

The dataset uses a unified schema where `record_type` indicates row type:
- **observation**: Actual measured values (Findex surveys, operator reports)
- **event**: Policies, product launches, market entries
- **impact_link**: Relationships connecting events to indicators
- **target**: Official policy goals (e.g., NFIS-II targets)

### Data Sources
- Global Findex Database (World Bank)
- National Bank of Ethiopia (NBE)
- Ethio Telecom (Telebirr data)
- Safaricom Ethiopia (M-Pesa data)
- EthSwitch S.C. (P2P/ATM data)
- GSMA State of the Industry Report
- IMF Financial Access Survey
